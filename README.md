## 🎯 Sobre el Repositorio

> [!NOTE]
> Este repositorio consolida la experiencia práctica adquirida en **Procesamiento del Lenguaje Natural (NLP)** e **IA Generativa**, abarcando desde la vectorización clásica hasta el ajuste fino (*fine-tuning*) de modelos Transformers.

## 🚀 Cómo Ejecutar los Notebooks

> [!TIP]
> La forma más rápida de probar el código es usar las insignias **"Open in Colab"** en la tabla superior.

<details>
<summary>🔍 <b>Haz clic aquí para ver las instrucciones de ejecución local</b></summary>

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/CodingIA.git
   cd CodingIA
   ```

2. **Instalar dependencias recomendadas:**
   ```bash
   pip install numpy pandas scikit-learn transformers torch
   ```

3. **Ejecutar Jupyter Lab/Notebook:**
   ```bash
   jupyter lab
   ```
</details>
