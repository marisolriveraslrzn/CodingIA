## 🎯 Sobre el Repositorio
El objetivo de este proyecto es explorar y aplicar distintos algoritmos y técnicas de **Procesamiento de Lenguaje Natural (NLP)** e **Inteligencia Artificial**, abordando desde representaciones vectoriales básicas hasta ajuste fino (*fine-tuning*) de modelos de lenguaje.

---

## 📂 Estructura de Proyectos

A continuación se detallan los cuadernos (*notebooks*) disponibles en este repositorio:

| Archivo / Proyecto | Descripción | Estado |
| :--- | :--- | :---: |
| 🔤 **`Vector_Representation.ipynb`** | Introducción a técnicas de embeddings y representación de texto en vectores (TF-IDF, Word2Vec). | Completo |
| 💬 **`Clasificador_Opiniones.ipynb`** | Modelo de análisis de sentimientos/opiniones para clasificación de texto. | Completo |
| ✍️ **`Generador_de_Texto.ipynb`** | Creación y entrenamiento de un modelo generativo de texto básico. | Completo |
| ⚙️ **`Text_generation_fine_tuning.ipynb`** | Ajuste fino (*Fine-Tuning*) de un modelo de lenguaje preentrenado para tareas específicas. | Completo |

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3.x
- **Entorno de Desarrollo:** Google Colab / Jupyter Notebooks
- **Librerías Principales:**
  - `numpy`, `pandas` (Manipulación de datos)
  - `scikit-learn` (Modelos clásicos de Machine Learning)
  - `transformers` / `huggingface` (Modelos de lenguaje)
  - `nltk` / `spacy` (Preprocesamiento de texto)
